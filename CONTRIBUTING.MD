# Contributing to the Lab Chronicle

Thank you for contributing to the Lab Chronicle.

This chronicle documents the academic, technical, and collaborative journey of the lab, including conferences, events, and reflections. Contributions from all lab members are encouraged.

---

# Contribution Categories

Currently, the chronicle contains the following sections:

- Conferences
- Lab Events
- Reflections

Please add new entries to the appropriate section.

---

# General Workflow

1. Fork the repository to your GitHub account.
2. Create or edit the appropriate Markdown (`.md`) file in the relevant section.
3. Add related images/assets if needed.
4. Commit your changes.
5. Create a pull request to submit your contribution.

Contributions can be made directly through the GitHub web interface without installing Git locally.

---

# File Naming Conventions

Use descriptive lowercase file names with hyphens.

Examples:

```text
2021-lab-retreat.md
first-conference-reflection.md
```

Avoid spaces in filenames.

---

# Folder Structure

```text
docs/
├── conferences/
├── events/
├── reflections/
└── assets/
```

Images should be stored inside:

```text
docs/assets/
```

Recommended organization:

```text
docs/assets/conferences/ubicomp2026/
docs/assets/events/lab-retreat/
```

---

# Adding Images

Example Markdown syntax:

```markdown
![Group Photo](../assets/conferences/ubicomp2026/group-photo.jpg)
```

Please compress large images before uploading.

Recommended:
- JPG format for photos
- Maximum width around 1600px

---

# Markdown Guidelines

Use:
- clear headings,
- concise writing,
- bullet points where appropriate,
- and descriptive titles.

Example structure:

```markdown
# Event Title

## Overview

## Highlights

## Reflections

## Photos
```
